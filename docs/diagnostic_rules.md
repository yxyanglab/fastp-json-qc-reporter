# 细菌转录组 fastp 异常模式规则

这些规则用于 fastp JSON 的初筛决策支持。它们不是根因诊断，只提供“可能原因”和“建议复查方向”。最终判断应结合 FastQC/MultiQC 图、比对率、rRNA 比例、参考基因组 GC 背景和实验分组。

## 决策等级

| 等级 | 含义 |
| --- | --- |
| `PASS` | 当前指标未发现明显异常，可以进入后续分析 |
| `WARN` | 指标有偏移或轻度异常，通常可继续，但建议记录并结合后续结果复查 |
| `FAIL` | 指标达到失败阈值或多指标共同异常，建议复查后再进入后续分析 |

## 异常模式

| 模式 | 触发条件 | 可能原因 | 建议复查 |
| --- | --- | --- | --- |
| 低质量 reads 与过滤损耗同时偏高 | 过滤率 `>=15%` 且 Q30 `<80%` | 测序质量偏低、接头/低质量尾端较多，或样本建库质量不稳定 | fastp per-base quality、adapter content、过滤前后 reads 数、后续 mapping rate |
| 过滤后 Q30 仍偏低 | Q30 `<80%`，但过滤率未明显升高 | 过滤后整体碱基质量仍不足，可能影响比对和定量稳定性 | read 末端质量曲线、测序批次、是否需要更强尾端修剪 |
| 过滤率偏高但 Q30 尚可 | 过滤率 `>=15%` 且 Q30 未失败 | fastp 去除了较多低质量或过短 reads，但保留 reads 质量尚可 | 确认过滤后 reads 数是否满足分析深度，查看 too short reads 和 adapter trimming |
| GC content 超出默认范围 | GC `<35%` 或 `>65%` | 菌株自身 GC 背景特殊、rRNA/污染序列、样本混淆或建库偏好 | 与参考基因组或近缘菌 GC 比较，结合 mapping rate、rRNA 比例、物种注释判断 |
| 样本间 GC 系统性偏移 | 单样本或组中位数与总体中位数差异 `>=6%` | 真实分组差异、批次效应、污染或样本处理差异 | 结合分组、建库批次、mapping rate、PCA/聚类判断；若集中在同组需谨慎解释 |
| A/T 或 C/G 碱基组成偏差较大 | `\|A-T\|` 或 `\|C-G\| >10%` | 随机引物偏好、链特异性建库、read composition 偏差或污染 | fastp base content 曲线、FastQC per base sequence content、rRNA 去除效果、建库类型 |
| 碱基组成轻微偏差 | `\|A-T\|` 或 `\|C-G\| >5%` 且未超过失败阈值 | 细菌转录本组成或建库偏好导致的轻度偏移 | 通常可继续分析，但建议查看偏差是否集中在 reads 前端 |

## 为什么不写“根因诊断”

fastp JSON 只能提供 reads 质控层面的摘要指标。仅凭过滤率、Q30、GC 和碱基比例，无法直接确定污染、建库失败或测序试剂问题。因此本项目只输出“异常模式”和“建议复查方向”，避免把筛查规则误写成确定性生物学结论。
